# 6 Strings

A browser-based guitar learning demo with a beginner curriculum, chord diagrams, strumming practice, daily theory quiz, progress preview, and microphone tuner.

## Try it

Open the GitHub Pages website: https://xyroxbt.github.io/XyRoX/

Allow microphone access in your browser to use the tuner. Use headphones or a quiet room for more reliable pitch readings.

This is a learning-program demo. Playing checks are instructor-reviewed; grades and certificates are not external accreditation.
